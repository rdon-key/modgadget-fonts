The BSD 3-Clause License in the repository root applies only to source code
developed for ModGadget Fonts, including the conversion tools and runtime
code.

Font files, generated font data, and other derived assets remain subject to
the licenses of their original fonts.

When a font directory contains its own `LICENSE` file, that license applies
to the font files and generated font data in that directory, unless otherwise
stated in the directory's `README.md`.

Each font directory should include information about:

- The original font name
- The original author or copyright holder
- The applicable license
- The source from which the font was obtained
- Any modifications or subset generation performed

The inclusion of a font in this repository does not relicense it under the
BSD 3-Clause License.
